# Ablation: các biến thể của FPClose (ours)

Nguồn: `results/memory/basic_vs_optimized.csv` (mỗi dataset đo tại minsup giữa lưới). Giá trị = trung vị các lần OK. `mine_s` = chỉ khai thác (không gồm đọc/ghi). Bộ nhớ thực dùng = `mem_delta_mb` = max(peak RSS − baseline RSS, 0); 0 nghĩa là mức tăng nhỏ hơn nền Julia (~285 MB), không phân biệt được. `alloc_mb` = tổng cấp phát do Julia đếm. Trong ngoặc: chênh lệch so với `optimized` (dương = lớn hơn/chậm hơn).
